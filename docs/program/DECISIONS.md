# Decisions

## 2026-10-11

- Keep the application as a React + Vite single-page marketing site for now.
- Do not add a backend or database yet; use static content and local-state patterns for the first support pages.
- Prefer hash-based navigation for new support pages to minimize dependencies and keep the app stable.
- Maintain the current design language: dark UI, orange accents, and modular glass-card sections.
