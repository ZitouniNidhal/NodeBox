# Roadmap

## Current focus

- Finish the support and trust layer for the NodeBox landing experience.
- Add FAQ, contact, and legal pages to support adoption and product confidence.
- Maintain a lightweight single-page marketing structure until a real backend or workspace flow is required.

## Near-term

- Extend the docs experience with a dedicated getting started section.
- Add examples and a playground page for common runtime patterns.
- Evaluate whether a workspace dashboard should be local-only or backend-backed.

## Later

- Add a real project management dashboard.
- Introduce persistence, local storage or API-backed data models.
- Consider auth and user accounts only when the product direction requires multi-user workflows.
